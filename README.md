# Campus Nexus – Student Information Management using Props

React + Vite frontend (no backend).

## Run
    npm install
    npm run dev

## Structure
    src/
      App.jsx                  <- holds state, passes everything down as props
      main.jsx
      styles.css
      data/students.js
      components/
        Header.jsx  Footer.jsx  Hero3D.jsx  Controls.jsx
        StudentList.jsx  StudentCard.jsx  AddStudentModal.jsx  Background.jsx
